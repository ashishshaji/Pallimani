# ⛪ Pallimani

A fast, single-page directory of **Mass timings for every parish church in the Palai Diocese, Kerala**. 📍✨

## 🌟 Features

- 📅 Mass times for all **seven days**, opening automatically on **today's schedule**
- 🕒 An hour-by-hour chart showing how many churches have a Mass starting at each hour; tap an hour to filter
- 🔍 Search by **parish, place, or address**, and filter by **forane**
- ⭐ Highlights the **next Mass** and can hide Masses that have already passed
- 🙏 Devotions such as **Adoration** and **Rosary** shown alongside Mass times
- 🏛️ Church details including **address, vicar, founding year, and tap-to-call phone number**
- 📱💻 Works seamlessly on both **phones and desktops**
- ⚡ No dependencies and **no build step required**

## 📊 Data

Mass timings come from the church profiles on **palaidiocese.com**. 🌐

⚠️ Timings may change from time to time, so please confirm with the parish before travelling.
